Add a "Brief me" precinct briefing card to Lumina Precinct Agent: an illustration made by Meta's Muse Image, with the precinct's verified figures laid over it as real text.

The rule that shapes everything: the agent never invents numbers (see `AGENTS.md`). Image models also render text and numbers badly. So Muse Image draws a picture with **no text and no numbers**; every figure on the card comes from the governed metrics, rendered by our code, with its source and date. The picture is labelled "Illustration: AI-generated (Muse Image)".

Context: read `AGENTS.md`. Model API notes: `docs/spikes/2026-10-28-day1.md` (Muse Image is `muse-image-1.0` at `${META_BASE_URL}/images/generations`, OpenAI-compatible; key `MODEL_API_KEY`; base URL default `https://api.meta.ai/v1`). Verified figures: the metrics behind `/api/v1/metrics` (`src/app/api/v1/metrics/route.ts`, `src/server/metrics/catalogue.ts`, `src/server/metrics/query.ts`) and land use behind `/api/v1/landuse/[station]`. Station data: `src/lib/stations.ts`; line colours `src/lib/lines.ts`; land-use categories `src/lib/landuse.ts`. Portal UI: `src/components/portal/` (snapshot in `PrecinctSnapshot.tsx`, Meta models list in `ModelsPanel.tsx`, drawers use the `.drawer` styles in `src/app/globals.css`).

Build:
1. `src/server/briefing.ts`:
   - `briefingFacts(db, station)`: the figures for the card from the existing metric queries (unit median within 800 m, unit price change over 12 months, house median within 800 m, station trips over 12 months and their change, and the top three land-use categories within 800 m), each with label, display value, source and as-of date. Suppressed or missing figures are left out, never estimated.
   - `briefingPrompt(station, landUse)`: an image prompt describing the precinct's character only (for example "a calm isometric illustration of a Sydney rail station precinct: mid-rise apartments around the station, low-rise houses with gardens beyond, a train line in orange, tree-lined streets"), driven by the land-use mix and the station's lines. It must say: no text, no letters, no numbers, no logos, no real brand names, no identifiable people.
   - `generateIllustration(prompt)`: calls Muse Image, returns a PNG/JPEG data URL plus model and ms. Timeout 60 s. Clear error when the key is missing.
   - Cache the illustration per station (in memory plus a file under the OS temp dir) for 7 days, so repeated "Brief me" clicks cost nothing.
2. `src/app/api/v1/briefing/[station]/route.ts`: `GET` returns `{ station, name, image, image_model, image_ms, cached, figures, generated_at }`. 404 unknown station; 503 with a plain message when Muse Image is unavailable (the figures can still be returned with `image: null`). Rate limited like `/ask`. Same auth as the other `/api/v1` routes.
3. Mock: add `/images/generations` to `spikes/mock-meta-server.ts` returning a small placeholder PNG.
4. UI: a "Brief me" button (with the Meta dot) in the precinct snapshot header. It opens `BriefingCard.tsx` in a drawer: the illustration at the top with the "Illustration: AI-generated (Muse Image)" label, the station name and line badges, the figures as tiles (value, label, source and date), and a footer line "Figures: governed NSW open data, checked. Not financial advice." Buttons: "Download card" (compose the card into a PNG with a `<canvas>`, no new dependencies) and "Close". Show a loading state while the image is made ("Muse Image is drawing the precinct…"), and the figures alone if the image fails.
5. Models panel: Muse Image and Muse Voice Transcribe show "Live" when the server has a Meta key (the health check reports provider `meta`) and their features exist; otherwise "Offline: no API key set". Update the "where" lines to the real places (Microphone in the question box; "Brief me" on the precinct snapshot).
6. Tests: `tests/briefing.test.ts` checks that `briefingPrompt` always contains the no-text rule and never contains a digit, and that `briefingFacts` returns only figures present in the database (use the demo/seeded PGlite DB the other tests use).

Do not change the agent, the verifier, the SQL guard or the database schema. Run `npm test`, `npm run typecheck`, `npm run lint`. CHANGELOG (Sydney date): "Brief me: precinct briefing card with a Muse Image illustration and verified figures (built with Muse Code)."
