Add an "Opportunity sites" layer to Lumina Precinct Agent: surface car parks and construction sites that SAM 3.1 found within 800 m of each featured station as map polygons, with an agent tool, so a developer can see candidate land near a station at a glance.

Context: read `AGENTS.md` and the header of `scripts/sam/batch.ts`. The SAM batch caches masks per tile under `data/derived/sam/cache/` (file names encode station, resolution, chip grid position and tile `q<x>_<y>_<size>`); `scripts/sam/check.ts` already maps cached masks back to chip pixels. Chip geography: chips are 1024 px at `RES` metres per pixel, laid out in an n×n grid centred on the station (see the chip centre maths in `batch.ts`). Database loaders live in `src/server/db/` (follow `real-cover.ts`), schema in `db/schema.sql` (governed views are granted to `agent_ro`). Map layers: `src/components/portal/MapView.tsx`, `LayerPanel.tsx`, `MapGuide.tsx`. Agent tools: `src/server/tools/index.ts`.

Build:
1. `scripts/sam/sites.ts` (npm `sam:sites`): from the cache only (no SAM calls), turn every `parking lot` and `construction site` mask into a polygon in lon/lat (trace the mask outline, convert chip pixels to Web Mercator using the chip's centre and RES, then to WGS84; simplify to about 1 m). Merge overlapping polygons of the same class, drop parts under 300 m², keep those whose centroid is within 800 m of the station. Write `data/derived/sam_sites.geojson` with properties: station_id, class, area_m2, distance_m (to the station), and `method: "sam-3.1"`.
2. Schema: table `sam_sites (id, dataset_id, station_id, class, area_m2, distance_m, geom 4326)` and view `v_sam_sites` granted to `agent_ro`. Loader `src/server/db/real-sites.ts` (dataset `sam_sites`, source "Meta SAM 3.1 on NSW aerial imagery"), wired into the local DB build like the other loaders and into `db:setup` (`--load-sites`, also part of `--load-real`). Test it like `tests/cover.test.ts`.
3. `GET /api/v1/layers/sites?station=` returning the GeoJSON for one station.
4. Map: "Opportunity sites (SAM 3.1)" toggle in the Layers panel with the Meta dot; car parks outlined in blue, construction sites in amber, hover shows class, area (m², rounded) and distance from the station. Explain it in `MapGuide.tsx`: found by SAM 3.1 on one aerial capture; candidates for investigation only, not zoning or ownership advice.
5. Agent tool `find_sites({ station, class?, min_area_m2? })`: facts via `ctx.facts` for count, total area and the three largest (area, distance), plus a `show_layer` action. The wording note pushed to the composer must say "candidate sites for further investigation; zoning and ownership not checked". Add two eval questions.

Never commit anything under `data/`. Run `npm test`, `npm run typecheck`, `npm run lint`, then `npm run sam:sites` and report the number of sites per station. CHANGELOG (Sydney date): "Opportunity sites: car parks and construction sites found by SAM 3.1 near stations (built with Muse Code)."
